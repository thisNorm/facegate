| 2026-11-05 | D-63 | **얼굴 인식을 단말 안에서도 할 수 있게 함.** 관리자 웹 설정 '얼굴 인식 위치'에서 AI 서버(지금처럼 PC가 영상을 받아 감)와 단말을 고른다. 기본은 AI 서버. 단말을 고르면 단말이 1분마다 등록 사진 목록을 보고 바뀌면 다시 받아, 0.5초마다 장면 한 장을 AI팀 코드(SCRFD-10G 얼굴 찾기 + LVFace-T 인식, ONNX CPU)로 알아본다. 얼굴이 화면 높이 25% 이상, 가운데, 정면, 연속 3장일 때만 사람으로 보고, 새 사람이면 서버에 appear를 한 번 보낸다. 판정과 같은 사람 합치기는 AI 서버 appear와 같은 길. 얼굴 찾기 입력은 AI팀 기본 640 대신 320(RK3576에서 640은 장면당 1.2초, 앱 CPU 49%, 85도까지, 320은 0.28초, 18%). 두 모델의 학습 가중치는 비상업 연구용이라 운영 전에 허가를 받거나 바꿔야 한다. 둘 다 켜 두면 같은 사람이 두 번 기록될 수 있어 AI 서버 프로그램은 끈다 |

## 3. 참고: NFC 스티커 방식 검토 (Q-22)

사진 사원증 뒷면에 NFC 스티커(지름 25~30mm, 장당 수백~2천 원대)를 붙이면 카드를 새로 만들지 않고도 NFC 출입이 가능합니다. 단말의 안드로이드 NFC로 그대로 읽힙니다.

| 스티커 종류 | 가격 | 복제 위험 | 판단 |
|---|---|---|---|
| NTAG213/215 (가장 흔함) | 매우 쌈 | **높음** — 고유번호(UID)만 쓰면 휴대폰 앱으로 흉내 낼 수 있음 | 비권장 |
| MIFARE Classic 1K | 쌈 | **높음** — 암호가 이미 뚫려 복제 장비가 흔함 | 비권장 |
| **NTAG 424 DNA** | 보통 | 낮음 — 태그할 때마다 바뀌는 암호 값(SUN 메시지)을 서버가 검증 | **권장** |
| MIFARE DESFire EV2/EV3 | 비쌈 | 낮음 — 암호 인증 | 가능 (스티커 형태는 구하기 어려움) |

주의할 점:
- 스티커를 떼어 다른 카드에 붙이면 그 카드로 출입됩니다. 대신 스티커는 직원 1명에 묶여 있으므로 분실 카드와 같이 정지하면 됩니다 (FR-N-19).
- 휴대폰 케이스·지갑에 넣고 대면 인식 거리가 짧아질 수 있습니다 → 시범 운영에서 확인.
- **2026-10-27 결정 (D-12).** NFC 요구사항은 02 문서 1.4절로 다시 정리했습니다.
