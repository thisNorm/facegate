## 1. 기능 요구사항

### 1.3-1 핸드폰으로 열기 (FR-P) — D-62

얼굴이 안 될 때 직원 본인 핸드폰으로 연다. 핸드폰에는 앱을 깔지 않는다.

| ID | 요구사항 | 우선순위 | 비고 |
|---|---|---|---|
| FR-P-01 | 관리자 웹 직원 상세에서 등록 QR(링크)을 만든다. 24시간 안에 한 번만 쓸 수 있고, 본인이 핸드폰으로 열어 "이 핸드폰으로 등록"을 누르면 그 브라우저가 등록된다 | 필수 | 링크 미리 보기가 등록을 써 버리지 않게 누를 때만 |
| FR-P-02 | 단말은 서버가 준 일회용 주소(60초, 한 번만)를 NFC 태그로 항상 내보내고, 'QR로 열기' 버튼을 누르면 같은 주소를 QR로 30초 띄운다 | 필수 | 20초마다, 판정 뒤 바로 새 값 |
| FR-P-03 | 핸드폰이 주소를 열면 등록 쿠키와 함께 서버로 보내고, 서버는 얼굴과 같은 규칙으로 판정해 열고 단말에 결과를 보낸다. 출입 기록 인증 수단은 '핸드폰' | 필수 | 등록 안 된 핸드폰은 값을 써 버리지 않음 |
| FR-P-04 | 관리자 웹에서 직원의 등록된 핸드폰을 보고 해제한다. 등록 링크와 해제는 작업 이력에 남는다 | 필수 | |
| FR-P-05 | `PHONE_BASE_URL`이 없으면 기능이 꺼지고 단말 버튼과 태그도 나오지 않는다 | 필수 | 정식 인증서가 있는 회사 도메인 권장 |

### 1.4 NFC 출입 (FR-N) — D-12

> 2026-11-04 (D-62): 스티커 방식은 1.5차로 미루고, 대체 수단은 먼저 1.3-1 핸드폰으로 열기로 한다.

얼굴 인식이 안 될 때 **사진 사원증 뒷면의 NTAG 424 DNA 스티커**를 단말에 대서 출입합니다. 암호 키는 서버에만 있고, 단말은 읽은 값을 서버로 넘기기만 합니다.

#### 출입 (태그 → 판정)

| ID | 요구사항 | 우선순위 | 비고 |
|---|---|---|---|
| FR-N-01 | 단말은 항상 NFC 태그를 기다린다 (얼굴 인식과 동시 동작) | 필수 | 판정 화면 표시 중에도 |
| FR-N-02 | 태그 시 스티커의 SUN 값(암호화된 UID·카운터 + CMAC)을 읽어 서버로 보낸다 | 필수 | IF-2 `nfc_tap` |
| FR-N-03 | 서버는 SUN 값을 복호화·검증해 UID를 얻는다. **CMAC 불일치 = 복제·위조 → 거부 + 경보** | 필수 | |
| FR-N-04 | 서버는 카운터가 마지막 값보다 커야만 통과시킨다 (같은 값 재사용 = 재전송 공격 → 거부) | 필수 | |
| FR-N-05 | UID로 스티커·직원을 찾고, 얼굴과 **같은 판정 규칙**(재직·권한·시간대·중복 개방, FR-S-04·08)을 적용한다 | 필수 | |
| FR-N-06 | 분실·정지·회수된 스티커는 즉시 거부하고 경보 기록 | 필수 | |
| FR-N-07 | 같은 스티커를 대고 있는 동안 반복 전송하지 않는다 (2초) | 필수 | |
| FR-N-08 | 태그 순간 "띡" 소리·진동, 결과는 얼굴과 같은 화면 (T-02/T-03) | 필수 | |
| FR-N-09 | 태그부터 결과 표시까지 0.5초 이내 | 필수 | |
| FR-N-10 | 서버 연결이 끊기면 NFC로도 열 수 없다 ("점검 중") | 필수 | 단말 단독 개방 금지 (NFR-05) |
| FR-N-11 | NFC 인증 방식은 관리자 설정: **`NFC만`**(기본) / **`얼굴+NFC`**. `얼굴+NFC`는 적용 시간대 지정 가능 (예: 22:00~07:00, 그 외 시간은 NFC만) | 필수 | D-23 |
| FR-N-22 | `얼굴+NFC`일 때: 같은 게이트에서 같은 직원의 얼굴 인식과 NFC 태그가 **10초 안에 둘 다** 들어오면 개방 (순서 무관). 하나만 오면 단말에 "사원증을 대주세요" / "얼굴을 봐주세요" 안내. 얼굴만 단독 통과도 이 시간대에는 막힘 | 필수 | D-23 |

## 2. 비기능 요구사항 (NFR)

| ID | 분류 | 요구사항 | 비고 |
|---|---|---|---|
| NFR-01 | 성능 | 얼굴이 카메라 인식 범위에 들어온 뒤 게이트 열림까지 **1초 이내** (목표 0.5초) | 1단계에서 실측 |
| NFR-02 | 성능 | 직원 50~200명. 출근 피크 10분에 200명(분당 20명) 처리, 레인당 분당 15명 이상 | Q-06 |
| NFR-03 | 정확도 | 타인 오인식(잘못 열림) 0건 목표, 본인 거부율 3% 이하 | 시범 운영에서 측정 |
| NFR-04 | 보안 | 사진·영상 위조(라이브니스) 대응 | AI 서버 지원 여부 Q-10 |
