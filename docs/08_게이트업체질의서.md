# 08. 스피드게이트 업체 질의서

> 사용 시점: **게이트가 선정된 뒤** 해당 업체에 보냅니다 (D-27). 답변을 받으면 04 문서 IF-3의 어댑터를 그 게이트에 맞춰 만듭니다.

> 사옥 로비 스피드게이트 설치 건 관련 문의드립니다. 얼굴인식과 개방 제어는 저희 시스템에서 담당하며, 게이트에 열림 신호를 보내는 방식으로 연동하려 합니다. 아래 항목에 답변 부탁드립니다.

## 1. 제어 신호 (Q-03)

1. 외부에서 게이트를 여는 입력 방식은 무엇입니까? (무전압 드라이 접점 / Wiegand / RS-485 / TCP·IP 명령)
2. 드라이 접점이라면 필요한 펄스 길이(ms)와 단자 위치는?
3. RS-485·TCP 방식이라면 프로토콜 문서를 제공해 주실 수 있습니까?
4. 입장·퇴장 방향별로 열림 입력이 따로 있습니까?

## 2. 닫힘·통과 감지 (Q-04)

5. 사람이 통과하면 자동으로 닫힙니까? (별도 닫힘 신호가 필요한지)
6. 열림 신호 후 아무도 통과하지 않으면 몇 초 뒤 닫힙니까? 시간 설정이 가능합니까?
7. "통과 완료" 신호를 접점 등으로 출력할 수 있습니까?
8. 꼬리물기(1인 개방에 2인 통과)·역방향 진입·무단 진입 경보 출력이 있습니까?
9. 열림 신호를 연속 2회 받으면 2명 통과가 허용됩니까? (직원이 손님을 데리고 들어가는 "동반 통과"에 필요합니다. 신호를 쌓아두는지, 통과마다 다시 보내야 하는지 알려주세요)

## 3. 안전

10. 정전 시 게이트 날개는 열립니까, 닫힙니까? 무정전(UPS) 내장 여부는?
11. 화재수신반 연동(화재 시 전체 개방) 단자가 있습니까?
12. 끼임 방지 센서는 어떻게 동작합니까?

## 4. 설치·운영

13. 게이트 상판이나 측면에 **8~10인치 안드로이드 단말**과 **소형 카메라**를 달 수 있는 브라켓·배선 홀이 있습니까? 전원(DC 12V/PoE) 공급이 가능합니까?
14. 레인 폭, 휠체어·짐 통과용 광폭 레인 옵션은?
15. 분당 최대 통과 인원은?
16. 관리자가 수동으로 여는 방법(버튼·키)은?
17. 배선 연결 시 저희가 준비할 것(릴레이 모듈 위치, 케이블 규격)은?
18. A/S 기간과 장애 시 출동 시간은?
